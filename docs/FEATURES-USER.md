# anoon — что умеет приложение (простым языком)

> anoon — анонимный чат-рулетка 18+. Знакомишься анонимно (только ник и #ID), а когда захочешь —
> открываешь профиль собеседнику, и вы становитесь друзьями с личной перепиской. Тёмное приложение
> для телефона (устанавливается как PWA). Всё на русском.

---

## Регистрация и вход

- **Через Google** — кнопка «Войти через Google».
- **Через Facebook** — кнопка «Войти через Facebook».
- **Через Apple** — «Продолжить через Apple» (появляется, если включено).
- **По почте и паролю** — «Регистрация по email»: почта, пароль, имя, пол (Мужчина/Женщина).
  После — письмо с подтверждением на почту (кнопка «Отправить снова», отсчёт 60 сек).
- **Забыл пароль** — «Восстановление пароля»: вводишь почту → приходит ссылка → задаёшь новый пароль.

**После регистрации — заполнение профиля:**
- Выбор пола (галочка «Понимаю» — **пол потом изменить нельзя**).
- Имя, фамилия (необязательно), возраст-диапазон (необязательно), фото (необязательно).

**#ID** — твой пятизначный номер (например `#00001`), выдаётся автоматически и никогда не меняется.

## Главный экран — поиск собеседника

- Сверху: логотип «anoon», кнопка установить приложение, кнопка уведомлений (колокольчик),
  твоя карточка (аватар + ник + #ID).
- **Фильтры перед поиском:**
  - «Ваш возраст» — выбираешь свой диапазон (18–21 / 22–25 / 26–35 / 36+), обязательно.
  - «Возраст собеседника» — можно отметить несколько диапазонов.
  - Пол собеседника подбирается автоматически противоположный (мужчина ищет женщину и наоборот).
- Кнопка **«Начать чат»** → идёт поиск («Ищем собеседника…», пульсирующие круги, кнопка «Отмена»).
  Подбор идёт по фильтрам; если долго никого — фильтр смягчается (только по полу).
- Нашёлся собеседник → попадаешь в анонимный чат.

## Анонимный чат (рулетка)

Собеседник виден как «Собеседник» + его #ID (без имени и фото).

**Что можно:**
- Писать текст (Enter — отправить).
- Видеть, когда собеседник **«печатает…»** или **«записывает голос…»**.
- Онлайн-точка (в сети / не в сети).
- **Статусы своих сообщений:** ✓ отправлено · ✓✓ доставлено (серые) · ✓✓ просмотрено (синие).
- **Время** у каждого сообщения (ЧЧ:ММ).
- **Ответить на сообщение** (цитата).
- **Удалить своё сообщение**.
- **Эмодзи** через пикер.
- **Отправлять медиа**: фото, видео, голосовые (см. ниже).
- **Раскрыть профиль** — главная фишка (см. «Дружба» ниже).
- Меню чата (⋮): **Завершить разговор**, **Пожаловаться**, **Заблокировать**.

**Завершение разговора:** любой может завершить → окно «Разговор завершён» + **оценка собеседника**
смайликами (😡🙁😐🙂😍 — Плохо…Отлично) или «Пропустить».

---

## Медиа (фото, видео, голос)

- **Фото/видео** — кнопка-скрепка (можно выбрать несколько). Перед отправкой — превью с миниатюрами,
  можно убрать лишнее. Фото сжимаются для скорости.
- Собеседник сразу видит **размытую превьюшку** (как в Telegram), пока грузится полное.
- **Полноэкранный просмотр**: тап по фото/видео → открывается на весь экран. Зум пальцами (щипок),
  двойной тап — приблизить, свайп в сторону — листать, свайп вниз или тап по фону — закрыть,
  счётчик «1 / N».
- **Голосовые**: зажать/нажать микрофон → идёт запись (таймер, живой эквалайзер, вибрация).
  Отправить (✓) или отменить (✗). У сообщения — круглая кнопка play, волна с прогрессом,
  перемотка пальцем, точка «не прослушано», скорость 1x/1.5x/2x.
- **Одноразовые фото/видео** («Одноразовое» при отправке): собеседник может открыть **1 раз**,
  потом медиа исчезает («просмотрено») — навсегда, даже если он сменит устройство.

## Дружба = раскрытие профиля

Пока чат анонимный, вы видите только #ID. Чтобы открыть имена/фото и получить личную переписку:

- В анонимном чате — кнопка **«Раскрыть профиль»** → у собеседника появляется предложение
  с кнопками **«Открыть» / «Отклонить» / «Заблокировать»**.
- Если он принял — **оба видите полный профиль** (имя, фото, возраст, пол) и становитесь **друзьями**.
  Появляется уведомление «Профили открыты — вы теперь друзья».

**Раздел «Друзья»:**
- **Поиск** по #ID или нику. Можно отправить запрос дружбы прямо из поиска.
- **Входящие заявки** — «Открыть» (принять) / «Отклонить».
- **Список друзей** — аватар, статус (в сети / был(а) N назад), **бейдж непрочитанных**.
  Тап → личная переписка. «Убрать» — удалить из друзей (личка пропадёт; профиль уже виден —
  анонимность не вернётся).
- **Приглашение по ссылке/QR**: в профиле есть QR-код и ссылка «добавить меня». Кто перейдёт —
  сможет отправить/принять запрос дружбы. Свою ссылку добавить нельзя.

**Личная переписка (друзья):** как обычный чат, но профили уже открыты, плюс **реакции на сообщения**
(двойной тап — ❤️; долгий тап — выбор ❤️ 👍 😂 😮 😢 🙏). Есть медиа, голос, статусы, время.

## Уведомления

- **Колокольчик** — вкладка «Уведомления». Приходят даже когда приложение закрыто (пуши копятся).
- Внутри: **заявки в друзья** прямо тут с кнопками «Принять»/«Отклонить», и лента уведомлений
  (с временем «только что / N мин назад / вчера…»). Тап по уведомлению → в нужное место.
- Кнопка «Прочитать все». **Бейджи** на вкладках нижней панели: «Уведомления» (непрочитанные),
  «Друзья» (новые заявки + непрочитанные сообщения). Кап «9+».
- **Push-уведомления**: включаются кнопкой-колокольчиком (запрос разрешения браузера). Есть баннер
  «Включите уведомления». На iPhone пуши работают только в установленном приложении (не в Safari-вкладке).

## Модерация со стороны пользователя

- **Заблокировать** собеседника (в меню чата, в предложении раскрытия, в поиске друзей) — вы больше
  не видите сообщения друг друга.
- **Пожаловаться** — окно с причинами: Спам/реклама, Оскорбления/травля, Непристойный контент,
  Подозрение на несовершеннолетнего, Мошенничество, Другое + комментарий. → «Спасибо, жалоба отправлена».
- Если тебя **замьютил** админ — вместо поля ввода надпись «Вы не можете отправлять сообщения»
  (читать можно). Если **забанил** — экран «Доступ заблокирован» (чат и поиск недоступны).

## Профиль и настройки

**Профиль:**
- Фото, #ID (не меняется), ник, имя, фамилия, **пол** (только для чтения, с замком), возраст.
- «Сохранить». Блок «Поделиться профилем» — QR + ссылка + «Скопировать ссылку». Ссылка на «Настройки».
  «Выйти».

**Настройки:**
- Смена ника. Ссылки «Профиль аккаунта», «Друзья».
- **Уведомления** — тумблер пушей + статус.
- **Заблокированные** — список, «Разблокировать».
- **Выход** — сбросить профиль на этом устройстве.

## Приложение (PWA) и мелочи

- **Установка**: кнопка «Установить» (Android/Chrome — сразу; iPhone — подсказка «Поделиться →
  На экран Домой»).
- **Офлайн**: если нет интернета — экран «Нет интернета» с кнопкой «Повторить».
- **Автообновление**: приложение само подхватывает новую версию (перезагрузка происходит тихо,
  когда возвращаешься на вкладку — не рвёт чат).
- **Нижняя панель** (4 вкладки): Главная · Друзья · Уведомления · Профиль. Прячется внутри чата.
- Зум страниц отключён (ощущение нативного приложения), безопасные отступы под вырез/статус-бар.
- **Живые обновления**: онлайн-статусы, бейджи непрочитанных и заявок обновляются сами, без ручной
  перезагрузки.
