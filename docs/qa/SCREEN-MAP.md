# Карта экранов anoon — рабочий документ для ручного UX-прохода

> Составлен 2026-08-06 по коду. Роутер: `src/components/anoon/AnoonApp.tsx:113-142` (`SCREENS`),
> типы маршрутов — `anoonNav.ts:6-34`. Витрина — `src/app/page.tsx:62-102`.
> Реальный апп: `http://localhost:8088/anoon`. Витрина: `http://localhost:8088/`.
> Аккаунты `admin1/admin1` (#00011, м) и `admin2/admin2` (#00012, ж).

**Два режима, и это меняет часть путей.** `USE_TINODE` (`NEXT_PUBLIC_USE_TINODE=1`) = «real».
Каждый экран рулетки внутри ветвится на `real` / mock. В mock-режиме есть демо-элементы,
которых в проде нет (и наоборот). Ниже помечено, где это влияет на достижимость.

**Стартовая точка.** Апп грузится в `onboarding` (`AnoonApp.tsx:238`), **кроме** случая
восстановленной сессии: если в localStorage есть токен — сплэш «anoon» и сразу `chats`
(`AnoonApp.tsx:275-284`). Чтобы гарантированно начать «с чистого логина» — выйти через
Профиль → Настройки → Выход, либо очистить localStorage.

**Три навигационных глагола** (`anoonNav.ts:52-61`): `push` (добавляет в стек, есть «назад»,
въезд справа), `back` (выезд слева), `go` (сброс стека, кросс-фейд). Где ниже написано
`go`, кнопки «назад» на следующем экране **не будет**.

## 3. Недостижимо без ухищрений

Здесь и прячутся визуальные дефекты — эти состояния никто не видит.

### 3.1 Маршруты-сироты (в роутере есть, `push`/`go` на них нет ни одного)

| Маршрут | Почему недостижим | Как посмотреть |
|---|---|---|
| `conversation-ended` | сам экран достижим **инлайн** из анон-чата (§2); отдельный маршрут-дубль не вызывает никто | вкладка `a/Оценка` на витрине |
| `reveal-prompt` | так и задумано — в `AnoonApp.tsx:96-99` написано «standalone route for direct addressability / QA», реальный поток инлайновый | вкладка `a/Раскрытие` |
| `media-viewer` (`AnoonMediaViewerDemo`) | пуш стоит **только в mock-ветке** обоих чатов (`AnoonAnonChat.tsx:1063-1071` и `AnoonPrivateChat.tsx:986-995` — оба под `{!real && …}`). При `USE_TINODE=1` этот демо-пузырь не рендерится вообще | вкладка `a/Просмотр медиа`, либо поднять фронт без `NEXT_PUBLIC_USE_TINODE` |
| `offline` | как маршрут — никем; работает только как глобальный оверлей | DevTools → Offline |

### 3.2 Состояния, достижимые только через ошибку сервера

Все три — **новые в этой волне** и не видны ни в одном штатном сценарии:

| Состояние | Где | Как спровоцировать |
|---|---|---|
| «Не удалось отправить жалобу…» | `AnoonReport.tsx:191-196`, флаг `failed` | DevTools → Network → блокировать `POST /api/reports`, затем отправить жалобу. Лист остаётся открытым, причина и текст сохраняются |
| Состояние отправки жалобы (`sending`) | `AnoonReport.tsx`, кнопка заблокирована | троттлинг сети до «Slow 3G» и тап по «Отправить» |
| «Не удалось заблокировать. Попробуйте ещё раз.» | `AnoonAnonChat.tsx:735-739` | блокировать `POST /api/roulette/block`, затем ⋮ → «Заблокировать» в анон-чате |

### 3.3 Прочее труднодостижимое

- **Бан / мьют** — реального триггера нет, только демо-строки в Настройках (§1.5).
- **`partnerId === "—"`** (`AnoonAnonChat.tsx:423-427`) — когда нет ни `peerHashId`, ни
  `peerAlias`. Бывает на пути восстановления (`/roulette/status`) в момент до прихода алиаса.
  Провоцируется: открыть анон-чат, перезагрузить страницу.
- **Занятая линия** (`AnoonApp.tsx:341-348`) — входящий звонок во время другого звонка,
  отбивается как «busy». Нужны три аккаунта.
- **Тост «Собеседник недоступен»** — позвонить тому, кто закрыл вкладку.
- **Бейджи `9+`** (`_shared.tsx:112-114`) — больше девяти непрочитанных/заявок.

## 4. Только на витрине, в реальном аппе не существуют

## 6. Экраны, где визуальные дефекты вероятнее всего — ранжировано

Основано на том, что реально трогала волна (диффы `AnoonAnonChat` +56, `AnoonReport` +87,
`AnoonApp` +4, `callStore` +8, `slices` +5) и на прошлой сессии по медиа.

### 6.1 🔴 Анонимный чат — шапка и подзаголовок (`AnoonAnonChat.tsx`)

Строка идентификатора сменила и длину, и алфавит: `#00012` (6 символов, цифры) →
`~K7X2QM` (7 символов, заглавные буквы). Что смотреть:

- **`tabular-nums` на строке идентификатора** (`:882`). Табличные цифры — фича для
  выравнивания **цифр**; на строке из `~` и заглавных букв она либо ничего не даёт,
  либо даёт разреженный, «дырявый» трекинг. Смысл, ради которого класс ставили, исчез.
- **Подзаголовок «Вы общаетесь анонимно · {partnerId}»** (`:990`) — стал на символ длиннее
  в однострочной полосе. Проверить на 390 px и в масштабе фрейма < 1.
- **Блок имени** (`:879-885`) — `min-w-0 flex-1`, у имени `truncate`, а у строки id
  `truncate` **нет**: она лежит в `flex` рядом со `StatusDot` и текстом активности
  («отправляет медиа»). Совпадение «алиас + точка + активность» — самая длинная комбинация;
  раньше она была короче на символ. Проверить именно её.
- **Фолбэк `"—"`** вместо прежнего `"#—"` — голое тире рядом со статус-точкой.

### 6.2 🔴 Входящий звонок от анонимного собеседника (`IncomingCall.tsx`)

`AnoonApp.tsx:353-354`: поиск по друзьям на алиасе не находит ничего (так и задумано), имя
становится `Собеседник ~K7X2QM`, а `peerId` — тот же `~K7X2QM`. Экран показывает
**один и тот же алиас дважды**, друг под другом (`IncomingCall.tsx:63` под именем).
Раньше для анонимного звонка этот путь просто не существовал — звонки шли только между
друзьями с настоящим именем. Плюс тот же `tabular-nums` на `:63`.
