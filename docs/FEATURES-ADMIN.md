# anoon · Админка — что умеет (простым языком)

> Панель модерации для anoon. Заходят модераторы и главные админы. Здесь видно пользователей,
> жалобы, баны, переписки, файлы, кто онлайн, и можно рассылать уведомления.

---

## Вход и роли

**Вход.** Логин по почте + паролю. Если у админа включена двухфакторка — ещё поле «код 2FA»
(6 цифр из приложения-аутентификатора). После 5 неудачных попыток вход временно блокируется
(«слишком много попыток, подождите»). Сессия живёт 8 часов, потом надо войти заново.

**Две роли:**
- **Модератор** — может: временно банить (обязательно указать срок), мьютить, разбирать жалобы
  (банить/отклонять), смотреть медиа и переписки, эскалировать.
- **Главный админ (super_admin)** — всё что модератор, ПЛЮС: перманентный бан (без срока),
  снятие бана, массовая рассылка уведомлений. Кнопки этих действий у модератора просто не видны.

**Выход.** Кнопка «Выйти» в шапке.

## Разделы (меню слева / бургер на телефоне)

Порядок в меню: **Обзор · Онлайн · Чаты · Жалобы · Пользователи · Баны · Файлы · Галерея ·
Рассылка · Журнал**. На компьютере — боковая панель, на телефоне — бургер открывает выезжающее
меню (закрывается само при переходе).

### Обзор
Стартовая страница. 4 карточки-плитки, каждая кликабельна:
- **Всего пользователей** → ведёт в «Пользователи».
- **Онлайн сейчас** → в «Онлайн»; тут же мелко разбивка 👧 девочки / 👦 мальчики.
- **Жалоб открыто** → в «Жалобы».
- **Активных банов** → в «Баны».

Цифры обновляются сами каждые 20 секунд. «Онлайн» = кто был активен за последние 90 секунд.

### Онлайн
Кто сейчас в сети (активность за 90 секунд). Обновляется вживую каждые 15 секунд.
Вкладки: **Все / 👧 Девочки / 👦 Мальчики**. По каждому: аватар-эмодзи, ник, #ID, «был N сек/мин
назад», пол, живая точка. Есть кнопка **скопировать #ID**. Если никого — «Сейчас никого нет онлайн».

### Чаты
Просмотр переписок пользователей (только чтение, для модерации). Две панели.
- Слева — список диалогов «А↔Б», сколько сообщений, время последнего. Список сам обновляется
  каждые 10 секунд. Если диалог активен прямо сейчас — мигает бейдж **«идёт»**.
- Справа — сама переписка, обновляется каждые 5 секунд, прокрутка вниз. Сообщения А слева, Б справа.
  Медиа показывается прямо тут: видео с плеером, голос с плеером, фото картинкой.
- Внизу подпись: «Просмотр только для чтения · аудит модерации».
- На телефоне: выбрал диалог → список прячется, стрелка «назад» возвращает к списку.

### Жалобы
Очередь жалоб. Сверху счётчик «N открытых». Две панели.
- Слева — список жалоб (можно отметить галочками, есть «Выбрать все»). У каждой: ник, #ID,
  начало комментария, тип жалобы цветным бейджем.
- Типы жалоб: **Спам · Оскорбления · Сексуальное · Противоправное · Другое**. «Противоправное»
  помечается красным «!» и меткой «Эскалация».
- Справа — карточка выбранной жалобы: ник/#ID, тип, дата, комментарий (или «Без комментария»),
  блок **«Медиа пользователя»** (можно посмотреть его файлы), и две кнопки:
  **«Забанить»** (откроется окно бана) / **«Отклонить»**.
- **Горячие клавиши** для быстрой разборки: J/↓ — следующая, K/↑ — предыдущая, B — забанить,
  X — отклонить.
- Массовые действия: отметил несколько → «Забанить выбранных» / «Отклонить выбранные»
  (с подтверждением).

### Пользователи
Список всех пользователей, отсортирован по числу жалоб (сверху самые проблемные).
- Колонки: **Ник** (эмодзи + имя, кликается в карточку), **#ID**, **Статус** (Забанен / Онлайн /
  Оффлайн), **Жалобы** (число), кнопка **«Бан»**.
- Галочки для массового бана — только у главного админа.
- **Карточка пользователя** (по клику на ник): большой эмодзи, ник, #ID, статус, число жалоб.
  Кнопки (если не забанен): **«Замьютить»** и **«Забанить»**. Ниже — его медиа для ревью.
  Подпись: «Личная переписка доступна в разделе «Чаты». Здесь — медиа пользователя для ревью.»

### Баны
Список банов с вкладками: **Активные / Истёкшие / Снятые** (с счётчиками).
- У каждого: ник + #ID, причина, бейдж состояния (Временный / Перманентный / Истёк / Снят).
- Кнопка **«Снять»** — только у активного бана и только у главного админа.

**Окно бана** (открывается из жалоб, списка или карточки):
- Причина чипами: Спам, Оскорбления, Сексуальное, Противоправное, Другое (при «Другое» — обязательно
  вписать текст).
- Срок: **Перманентный / 7 дней / 30 дней**. У модератора «Перманентный» недоступен (по умолчанию
  «7 дней»).

### Мьют (заглушка)
Открывается из карточки пользователя кнопкой «Замьютить». Мьют = не может писать, но может читать.
- Причина: Спам, Флуд, Оскорбления, Другое.
- Срок: **1 час / 24 часа / 7 дней** (всегда временный).
- Доступно и модератору.

### Файлы
Файловый менеджер по пользователям. Две панели.
- Слева — **папки по пользователям**: у каждого имя, #ID, сколько фото/видео, кнопка **скопировать
  #ID**, счётчик.
- Справа — галерея выбранного пользователя. Фильтр по датам (**С даты / По дату**, «Сброс»),
  постраничный вывод. Файлы тут показываются сразу (без размытия), на плитке — #ID владельца.

### Галерея
Все медиа всех пользователей сразу.
- Вкладки типа: **Все / Фото / Видео**. Фильтр по датам (С даты / По дату, «Сбросить даты»).
  Постранично. На каждой плитке — #ID владельца.

**Как показывается медиа (везде):** сетка плиток. В жалобах фото по умолчанию **размыты** — кнопка
**«Показать»** открывает по одному; в файлах/карточке — сразу. Клик по плитке → полноэкранный
просмотр (зум, видео с плеером). Если файл удалён/истёк — «Медиа удалено или истекло». Если ушёл на
эскалацию — «Заблокировано — передано на эскалацию» (смотреть нельзя). Кнопка **«Эскалировать»**
на плитке.

### Рассылка (только главный админ)
Массовое пуш-уведомление пользователям.
- Поля: **Заголовок** (обязательно, до 120 символов), **Текст** (до 300), **Ссылка при клике**
  (необязательно), аудитория кнопками **Всем / 👧 Девушкам / 👦 Парням**.
- Кнопка отправки активна только когда есть заголовок. Спрашивает подтверждение. После отправки —
  «Отправлено: N из M».
- Модератору вместо формы — надпись «Массовая рассылка доступна только super_admin».

### Журнал
Лента действий модерации в текущей сессии: баны, разбаны, муты, отклонения жалоб, эскалации,
просмотры приватного. У каждого — тип (цветной бейдж), кого, причина, время.
> Примечание: показывает действия текущей сессии в браузере, не всю историю из базы.

## Мелочи и поведение
- **Уведомления-тосты** внизу на каждое действие («Забанен: …», «Бан снят: …», «Скопировано: #…»),
  исчезают через ~3.5 сек.
- **Копирование #ID** — во многих местах (онлайн, файлы) есть кнопка, кладёт `#ID` в буфер.
- **Обновление вживую**: обзор 20с, онлайн 15с, список чатов 10с, открытая переписка 5с.
- **Поиск в шапке** («Поиск: ник или #ID») — пока не подключён (декоративный).
- **Приложение (PWA)**: админку можно установить как приложение (кнопка «Установить»/«На iPhone»).
  Работает офлайн-оболочка (кроме данных). Тёмная тема, портрет.
- **Безопасность**: без входа никуда не пускает (страницы → на логин, запросы → отказ).
  Пароли админов хешируются, вход по секретной cookie.
